1. Project Overview
SmartBudget Manager is a lightweight Excel tool designed to help small business owners,
administrative staff, and freelancers record income, track expenses, calculate monthly balances,
and visualize category spending.
2. System Requirements
To run and use this workbook, you need:
 Software: Microsoft Excel (2016, 2019, 2021, Microsoft 365, or equivalent compatible
spreadsheet software).
 Prerequisites: Basic knowledge of opening files, entering data into cells, and saving
spreadsheets.
3. Workbook Structure
The workbook is divided into three separate worksheets:
 Dashboard: Displays summary indicators (total income, total expenses, net balance),
expense distribution charts, and budget warnings.
 Transactions: The main log sheet used to enter daily income and expense transactions.
 Categories: Stores predefined transaction categories (e.g., Food, Transport, Rent, Health,
Education).
4. Getting Started
Follow these steps to start using the workbook:
1. Open the Workbook: Launch SmartBudget_Manager.xlsx in Excel.

2. Log Entries: Switch to the Transactions sheet and add your income/expense records:
 Enter the transaction date and description.
 Select a category from the provided dropdown list.
 Input the numerical amount.
3. View Summary Results: Open the Dashboard sheet to review automatically calculated
totals, dynamic charts, and financial indicators.
4. Track Budget Alerts: Pay attention to highlighted cells on the Dashboard, which indicate
when spending limits are exceeded.
5. Usage Rules &amp; Recommendations
 Do not overwrite formula cells: Avoid typing directly into calculation cells on the
Dashboard to prevent breaking automated functions (SUM, SUMIF/SUMIFS).
 Use dropdown categories: Always select categories from the list on the Transactions sheet
so summary formulas can accurately track totals.
